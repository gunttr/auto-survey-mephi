# CLI-клиент для оставления отзывов о преподавателях в системе МИФИ

Данный скрипт предназначен для автоматического оценивания преподавателей в трёх режимах: low, mid и high.

Если вы хотите оставить содержательный отзыв, самостоятельно отвечая на вопросы анкеты, перейдите на [survey.mephi.ru](https://survey.mephi.ru) — данный скрипт для этого не предназначен.

## Требования

Для запуска скрипта напрямую необходимы:

* Python 3;
* доступ к системе МИФИ;
* учётные данные пользователя МИФИ.

Для запуска через Docker требуется установленный Docker.

## Переменные окружения

Для работы программы необходимо установить две переменные окружения:

| Переменная       | Описание              |
| ---------------- | --------------------- |
| `MEPHI_USERNAME` | Логин в системе МИФИ  |
| `MEPHI_PASSWORD` | Пароль в системе МИФИ |

Рекомендуется хранить переменные в файле `.env`:

```.env
MEPHI_USERNAME=<ВАШ ЮЗЕРНЕЙМ>
MEPHI_PASSWORD=<ВАШ ПАРОЛЬ>
```

## Использование скрипта напрямую

### Клонирование репозитория

Склонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/gunttr/auto-survey-mephi.git
cd auto-survey-mephi
```

Создайте виртуальное окружение и установите зависимости. Для лучшей совместимости используйте версию Python `3.14` Например:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Создайте файл `.env` с учётными данными:

```.env
MEPHI_USERNAME=<ВАШ ЮЗЕРНЕЙМ>
MEPHI_PASSWORD=<ВАШ ПАРОЛЬ>
```

После этого скрипт можно запускать непосредственно через Python:

```bash
python3 script.py [ОПЦИИ] [ПРЕПОДАВАТЕЛИ]
```

### Опции

| Опция                         | Описание                                       |
| ----------------------------- | ---------------------------------------------- |
| `-h`, `--help`                | Показать справку и завершить работу            |
| `-p`, `--print`               | Вывести список преподавателей, не оценивая их  |
| `-s=ОЦЕНКА`, `--score=ОЦЕНКА` | Установить оценку для указанных преподавателей |

Доступные значения для `--score`:

* `low` — низкая оценка;
* `mid` — средняя оценка;
* `high` — высокая оценка.

Если `--score` не указан, используется `mid`.

### Формат преподавателей

Преподаватели передаются в формате:

```text
фамилия_инициалы
```

При указании нескольких преподавателей их необходимо разделять запятыми **без пробелов**.

Также вместо списка можно использовать `all`, чтобы оценить всех преподавателей.

Корректные варианты:

```text
сучков_мв
петров-сидоров_аб
СУЧКОВ_МВ
сучков_мв,волков_ве
all
```

Регистр букв не имеет значения.

Некорректные варианты:

```text
сучков мв
сучков_мв, волков_ве
```

В первом случае используется пробел вместо `_`, во втором — пробел после запятой.

### Примеры

Оценить конкретных преподавателей со средней оценкой:

```bash
python3 script.py сучков_мв,волков_ве
```

Оценить конкретных преподавателей с высокой оценкой:

```bash
python3 script.py -s=high сучков_мв,волков_ве
```

Оценить всех преподавателей:

```bash
python3 script.py all
```

Оценить всех преподавателей с низкой оценкой:

```bash
python3 script.py -s=low all
```

Вывести список преподавателей без их оценки:

```bash
python3 script.py --print
```

Посмотреть справку:

```bash
python3 script.py --help
```

## Использование через Docker

Скрипт также доступен в виде Docker-образа, опубликованного в GitHub Container Registry.

### Доступные образы

Для процессоров архитектуры **x86-64 (AMD64)**:

```text
ghcr.io/gunttr/auto-survey-mephi:v1-amd64
```

Для процессоров на базе **ARM64**:

```text
ghcr.io/gunttr/auto-survey-mephi:v1-arm64
```

Тег `latest` указывает на образ для архитектуры x86-64:

```text
ghcr.io/gunttr/auto-survey-mephi:latest
```

Таким образом, для ARM64 рекомендуется явно указывать тег `v1-arm64`, а для x86-64 можно использовать `v1-amd64` или `latest`.

### Запуск через Docker

Создайте файл `.env`:

```.env
MEPHI_USERNAME=<ВАШ ЮЗЕРНЕЙМ>
MEPHI_PASSWORD=<ВАШ ПАРОЛЬ>
```

Передайте его контейнеру с помощью `--env-file`:

```bash
docker run --rm \
  --name asm \
  --env-file .env \
  ghcr.io/gunttr/auto-survey-mephi:latest \
  --help
```

Вместо `latest` можно указать конкретный тег:

```bash
docker run --rm \
  --name asm \
  --env-file .env \
  ghcr.io/gunttr/auto-survey-mephi:v1-amd64 \
  all
```

### Примеры Docker

Оценить конкретных преподавателей со средней оценкой:

```bash
docker run --rm \
  --name asm \
  --env-file .env \
  ghcr.io/gunttr/auto-survey-mephi:latest \
  сучков_мв,волков_ве
```

Оценить преподавателей с высокой оценкой:

```bash
docker run --rm \
  --name asm \
  --env-file .env \
  ghcr.io/gunttr/auto-survey-mephi:latest \
  -s=high сучков_мв,волков_ве
```

Оценить всех преподавателей со средней оценкой:

```bash
docker run --rm \
  --name asm \
  --env-file .env \
  ghcr.io/gunttr/auto-survey-mephi:latest \
  all
```

Оценить всех преподавателей с высокой оценкой:

```bash
docker run --rm \
  --name asm \
  --env-file .env \
  ghcr.io/gunttr/auto-survey-mephi:latest \
  -s=high all
```

Вывести список преподавателей:

```bash
docker run --rm \
  --name asm \
  --env-file .env \
  ghcr.io/gunttr/auto-survey-mephi:latest \
  --print
```

Получить справку:

```bash
docker run --rm \
  --name asm \
  --env-file .env \
  ghcr.io/gunttr/auto-survey-mephi:latest \
  --help
```

Флаг `--rm` автоматически удаляет контейнер после завершения работы скрипта.
